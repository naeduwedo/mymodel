# ADR-004 — 能力驱动的多 GPU

**状态：** 已接受（spec §16，ADR-004）

## 上下文

多 GPU 支持是招牌功能，但各厂商与各运行时差异极大：P2P 是否可用、张量并行支持、统一内存与独立内存之别，以及驱动行为。

## 决策

每个运行时都声明自己的能力及其状态（`Supported / Unsupported / Experimental / Unknown`）。规划器只提出运行时已声明过的策略。P2P 以“已检测到”“驱动支持”或“基准验证”的形式报告 —— 绝不从设备列表推断。

## 后果

- Unknown 是一等状态；它绝不会被强制转换成正或假。
- 对于尚未证明支持张量并行的运行时，UI 不能提供张量并行选项。
- 用户得到的是一个解释（“该运行时不支持”），而不是五分钟后一次失败的加载。
