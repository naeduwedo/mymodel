# ADR-003 — 运行时适配器，不自研内核

**状态：** 已接受（spec §16，ADR-003）

## 上下文

编写 CUDA/ROCm/Metal 内核以及一个 Transformer 引擎是多年的工作量，还需要持续的硬件维护，而且它并不是本产品的差异化所在。

## 决策

通过实现公共 trait 的适配器集成成熟运行时（首先是 llama.cpp）：能力探测、内存估算、加载、推理、卸载。本仓库不实现任何推理内核。

## 后果

- 硬件支持跟随运行时的支持，我们必须按适配器、按版本如实报告这一点。
- 适配器版本偏差是真实风险：每个适配器都单独进行版本管理、测试和发布。
- 内核级优化应贡献到上游，那里才是它们该在的地方。
