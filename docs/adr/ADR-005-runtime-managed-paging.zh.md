# ADR-005 — 运行时管理的分页优先于引擎管理的分页

**状态：** 已接受（spec §16，ADR-005）

## 上下文

两个管理者搬同一个张量 —— 一个在运行时内部，一个在引擎里 —— 是等着发生的正确性缺陷，并可能破坏推理。

## 决策

优先使用运行时原生的 mmap、层卸载与专家缓存。只为那些暴露了张量生命周期、传输与同步原语的运行时启用引擎管理的张量分页。当引擎管理某个张量时，由引擎承担预算；当运行时管理时，引擎只做预算、配置与监控，绝不重复那一套记账。

## 后果

- `allow_engine_managed_paging` 默认为 false，并按运行时门禁。
- 内存报告必须区分“运行时管理”与“引擎管理”，这样 Memory Manager 页面上的数字在各处含义一致。
