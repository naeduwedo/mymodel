# ADR-006 — NVMe 是冷层

**状态：** 已接受（spec §16，ADR-006）

## 上下文

NVMe 的带宽，以及更关键的延迟，与 VRAM 相差数个数量级。把 NVMe 当作 VRAM 的扩展，会产生不可预测的解码时间，并磨损硬盘。

## 决策

NVMe 存放模型文件和冷数据，并配有有界、可取消、有度量的预取。它绝不会被呈现为等效内存。操作系统的 swap/pagefile 绝不会被用作模型分页机制。

## 后果

- 内存估算必须能按层解释；一个只有“配合 NVMe”才放得下的模型要如此报告，并说明预期的性能下降。
- 预取有硬性的字节预算（`max_prefetch_bytes`），并报告准确率。
- 对于依赖频繁换页（thrashing）的配置，绝不声称“它能跑”。
