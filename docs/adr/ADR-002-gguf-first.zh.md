# ADR-002 — GGUF 优先，而非仅支持 GGUF

**状态：** 已接受（spec §16，ADR-002）

## 上下文

GGUF 生态覆盖了 LLM 以及越来越多的视觉和音频模型，但多模态项目会正当地依赖一些并非 GGUF 的辅助组件（分词器、编码器、声码器）。

## 决策

把 GGUF 作为主要格式来管理。模型 manifest 可以声明非 GGUF 组件，但每一个这样的组件都必须显式列出，包含角色、大小和哈希。

## 后果

- 用户总能在下载数 GB 数据之前知道一个模型由什么组成。
- “它有一个 .gguf 文件”从不被当作模型可运行的证明。
- 兼容性检查的单位是 manifest，而不是文件扩展名。
