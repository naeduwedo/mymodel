# ADR-007 — 核心与推理工作进程是独立进程

**状态：** 已接受（spec §16，ADR-007）

## 上下文

模型加载与推理会牵涉驱动和多 GB 的内存分配；那里的崩溃是现实可能，绝不能拖垮管理器或丢掉用户的队列。

## 决策

核心（策略、账本、API）与运行时工作进程（推理）是独立进程。工作进程受监督：心跳、捕获的 stdout/stderr、取消与重启。UI 断开不会杀死工作进程，除非做了配置（`keep_workers_after_ui_exit`）。

## 后果

- 工作进程从 Task 1 起就存在（`gguf-worker`），尽管它还没有适配器，并以明确的“unsupported”代码退出。
- 进程间协议的设计从一开始就重要；它落在 Task 2。
- 工作进程崩溃恢复是受支持的场景，而不是异常场景。
